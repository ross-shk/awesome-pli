# Legacy PL/I Implementations and Tools

These projects are retained for historical interest. They may be inactive, dated, or limited to older platforms; consult each project's documentation before use.

- [PLI-2000](https://github.com/Steadsoft/PLI-2000) - A source-available PL/I compiler for 32-bit Windows. Its author describes the project as shelved and the compiler as dated; the repository documents building it with Visual Studio.
- [pl1gcc](https://sourceforge.net/projects/pl1gcc/) - An abandoned experimental PL/I front end for GCC; SourceForge lists its last update in 2013 and classifies it as alpha software.
- [SPF-Editor](https://github.com/michaelknigge/spf-editor) - An archive of the ISPF-like SPF/SE editor, including its final 2013 release and installer; the original author is deceased and the source code is unavailable.
- [Multics source code](https://github.com/dancrossnyc/multics) - Source for the Multics operating system, written largely in PL/I.
- [Multics PL/I](https://multicians.org/pl1.html) - History and design notes for the PL/I compiler used to build Multics.
