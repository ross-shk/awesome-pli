# Contributing

Suggestions and contributions are welcome. This list is a selective guide to useful PL/I software and learning material, not a directory of every PL/I-related link.

## What to suggest

- Recommend an item you have used or can confidently vouch for.
- Keep suggestions within the scope of PL/I compilers, development tools, libraries, code examples, and learning resources.
- Prefer maintained software with usable documentation. Put historically useful but inactive implementations in `legacy.md`, not the main list.
- Check that the link works and that the item is not already listed.

## How to contribute

- Open an issue to discuss substantial additions or changes, or submit a pull request for a focused update.
- Add an item to the bottom of the most relevant category.
- Use this format: `- [Name](URL) - Objective description.` Descriptions should start with a capital letter and end with a period.
- Keep category headings and the Contents links in sync when adding or renaming a section. Do not add the Contributing section to the Contents list.
- Check spelling, Markdown formatting, and link destinations before submitting.
